# Where Do High- and Low-Income Neighborhoods Cluster? (R)

GIS analysis of median household income across census tracts (default: Cook County, IL), written in R.
Blog post: [`blog/blog_post_5.md`](blog/blog_post_5.md).

## Structure
```
R/         00_install_packages.R, config.R, 01_download_data.R, 02_clean_merge.R,
           03_analysis_and_figures.R, run_all.R
data/raw/        downloaded TIGER/Line shapefile + ACS CSV (auto-created, git-ignored)
data/processed/  merged sf object (auto-created, git-ignored)
results/figures/ maps and histogram (PNG)
results/tables/  summary statistics (CSV)
blog/      blog post
```

## Data
- **ACS 5-year estimates**, tables B19013 (median household income) and B01003 (population), U.S. Census Bureau API (no key needed for this volume).
- **TIGER/Line census tract boundaries**, U.S. Census Bureau.

## Replication
Requires R (>= 4.1) and internet access on the first run. From the project root:
```r
source("R/00_install_packages.R")   # once
source("R/run_all.R")               # or: Rscript R/run_all.R
```
To study another county, edit `STATE_FIPS`, `COUNTY_FIPS`, and `AREA_NAME` in `R/config.R`. All figures and tables are generated by the scripts, not copied manually.

## Methods
1. Merge tract geometry with ACS income; suppressed values (negative sentinel codes) set to missing.
2. Choropleth map with quintile classes.
3. Global Moran's I (Queen contiguity, row-standardized, 999 permutations) on log income, via `spdep`.
4. Local Moran's I (LISA) to identify High-High / Low-Low clusters and spatial outliers (p < 0.05).
